DRIFT — installable app version

PUT IT ONLINE (pick one)
  Netlify Drop (easiest)
    1. On a computer, go to app.netlify.com/drop
    2. Drag this whole "Drift" folder onto the page.
    3. You get a web address straight away. Make a free account to keep it
       (otherwise it expires) and to rename it, e.g. drift-yourname.netlify.app
  GitHub Pages
    1. Make a new public repository, upload everything in this folder.
    2. Settings → Pages → Deploy from branch → main → / (root) → Save.
    3. Your address appears there after a minute.

INSTALL IT ON A PHONE
  Android (Chrome): open the address → menu ⋮ → "Install app" (or "Add to home screen" → Install).
  iPhone (Safari): open the address → Share → "Add to Home Screen".
  It opens full screen with its own icon, works offline, and keeps playing in the
  background (turn that off in the pause menu).

UPDATING
  Replace index.html with the new version (re-drag the folder on Netlify, or upload to GitHub).
  Installed copies pick it up the next time they open while online.
  Your worlds, explored maps and settings stay on each device.
